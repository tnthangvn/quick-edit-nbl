# Icons

Bản sao SVG nguyên gốc từ Lucide (`lucide-static` 0.460.0, giấy phép ISC), đúng bộ icon giao diện Spec Studio đang dùng. Nét `currentColor`, stroke 2, khung 24×24. Khi xem bằng `<img>` nét hiển thị màu đen; trong app dùng `lucide-react` để icon nhận màu chữ (`color-muted-foreground` khi nghỉ, `color-primary` khi đang bật).

| Icon | Dùng ở |
| --- | --- |
| `settings` | Header (mở Settings), Quick Setting Toolbar |
| `panel-left` | Thu gọn / mở Sidebar |
| `ellipsis` | Menu 3 chấm của spec |
| `send-horizontal` | Nút Send |
| `check` / `x` | Approve / Reject, trạng thái Synced, đóng Dialog |
| `refresh-cw` | Test Connection |
| `file-text` | File spec trong Sidebar, tab editor |
| `terminal` / `key-round` | CLI Agent Mode / API Key Mode |
| `loader-circle` | Syncing, đang chạy |
| `circle-alert` | Error, lỗi field, toast error |
| `info` | Toast info |
| `triangle-alert` | Toast warning |
| `trash-2` / `pencil` | Delete / Rename spec |
| `plus` | Tạo spec mới |
| `chevron-down` | Select |
| `bot` | Tin nhắn của Agent |
| `cloud-upload` | Force Sync, tab NotebookLM Sync |
| `git-compare` | Diff review, tool `propose_spec_update` |
| `search` | Tìm spec (dự phòng cho Sidebar) |
